Privacy Policy

Last updated: 2026-10-22

RPVM Workspace is a set of personal tools used by its owner to access the owner's own Google account data.

Data accessed

With the owner's consent, the tools may use the following Google API scopes, only for the owner's account:

  • Google Drive (https://www.googleapis.com/auth/drive): list, read, create, modify and delete the owner's files, as performed by the owner through rclone.

This list is updated if a tool requests additional scopes.

How data is used and stored

  • Data is transferred directly between Google and the owner's own computers. It is not sent to any server operated by the developer or any third party.
  • OAuth tokens are stored only in the owner's local configuration files.
  • No analytics, advertising or tracking is used. No data is sold or shared.

Google API Services User Data Policy

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the local configuration removes the stored tokens.
