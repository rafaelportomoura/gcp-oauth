RPVM Workspace

RPVM Workspace is a set of personal tools and automations used by a single person, its owner, to access the owner's own Google account data from the owner's own computers (for example, mounting the owner's Google Drive with rclone).

These tools are not offered to the public. There is no sign-up, no server and no user database: each tool runs locally and talks directly to Google APIs on behalf of the owner, using access the owner explicitly grants.
